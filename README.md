# Bike Sales Analysis & Interactive Dashboard (Excel)

## Project Overview
This project analyses bike sales data to explore customer purchasing behaviour and identify patterns related to income, age, education, marital status and commute distance.

The analysis was performed using Microsoft Excel, with PivotTables, PivotCharts and interactive slicers to create a dashboard.

## Tools & Skills
- Microsoft Excel
- Data Cleaning
- PivotTables
- PivotCharts
- Interactive Slicers
- Data Analysis & Visualisation

## Project Features
- Prepared and organised the dataset for analysis.
- Created PivotTables to summarise customer and purchasing data.
- Built PivotCharts to visualise key patterns.
- Developed an interactive dashboard with slicers for filtering the results.
- Explored bike purchases across different customer groups.

## Dashboard
The dashboard provides an interactive way to explore bike purchasing patterns using customer demographics and other characteristics.
